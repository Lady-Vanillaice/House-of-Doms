# House of Doms

Vercel-fertige Landingpage und Dashboard-Demo für eine einvernehmliche D/s-Management-Plattform.

## Lokal starten

```bash
npm install
npm run dev
```

Dann `http://localhost:3000` öffnen.

## Auf Vercel veröffentlichen

1. Dieses Projekt in ein neues GitHub-Repository hochladen.
2. In Vercel „Add New Project“ wählen.
3. Das Repository importieren.
4. Framework Preset: Next.js; danach Deploy.
